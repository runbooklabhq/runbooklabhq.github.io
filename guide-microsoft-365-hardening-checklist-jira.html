Teams external chats: file sharing default

MC1479514 switches on attachments in federated chats for tenants that haven't disabled them. On 15 October Microsoft removed the rollout dates; it still asks admins to set their choice by the first week of November. Set the policy explicitly and a later rollout changes nothing.

  Select FileSharingInChatsWithExternalUsers

FAQ

Is Teams turning on file sharing in external chats by default?

Yes, it's still planned, but without a date. MC1479514 switches on attachments in external (federated) chats for tenants that haven't explicitly disabled them. On 15 October 2026 Microsoft removed the rollout dates and said it will announce new ones in Message center; it still asks admins to set their choice by the first week of November. A policy set before the rollout is respected. Control T02 in the kit has both PowerShell options.

When is SMTP AUTH Basic auth switched off?

Per Microsoft's January 2026 timeline update, Basic auth for SMTP AUTH client submission is disabled by default for existing tenants in late December 2026. Control M01 uses the SMTP AUTH clients report to find printers and apps that will break.

Do the PowerShell checks change my tenant?

No. The scripts only call Get-* cmdlets and write a results CSV. The kit builder refuses any check containing Set-, New-, Remove-, Update-, Enable- or Disable- cmdlets.

Does the Jira CSV create sprints?

Stories carry a Sprint value and a sprint-N label. If your Jira project does not map the Sprint column on import, filter by label and bulk-move.
